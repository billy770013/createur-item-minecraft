PREMIERS PAS

Bienvenue dans votre atelier.

01 · Créez ou ouvrez un projet

Un projet regroupe tout votre add-on. Son namespace est le préfixe de vos identifiants, par exemple mon_addon:rubis. Le studio conserve vos projets dans son dossier data/.

02 · Imaginez votre contenu

Utilisez le menu pour créer des items, blocs, mobs, recettes, tables de butin, sons ou skins. Les textures se dessinent pixel par pixel, avec un aperçu 3D pour les contenus compatibles.

03 · Enregistrez vos modifications

Les boutons « Enregistrer » et le raccourci Ctrl S sauvegardent le projet. L’historique permet de retrouver les versions précédentes. Conservez une copie de votre dossier data pour sauvegarder l’ensemble du studio.

04 · Testez dans Minecraft Bedrock

Dans « Exporter & installer », consultez les vérifications puis téléchargez le fichier .mcaddon. Importez-le sur un appareil compatible et activez les packs dans un monde de test. L’installation directe sur serveur nécessite une configuration Linux spécifique ; l’export fonctionne indépendamment.
